# TelemetryLink — Захищена передача телеметрії низькошвидкісними каналами

Консольний застосунок на C# (.NET 8.0), що моделює повний двосторонній конвеєр підготовки, оптимізації, криптографічного захисту та відновлення телеметричних даних в умовах обмеженої пропускної здатності каналу зв'язку.

## Архітектура та етапи обробки даних

Програма послідовно виконує 5 основних етапів:
1. **Прогнозування ємності каналу (`MlpLab.cs`)** — багатошаровий перцептрон (MLP) з функцією активації сигмоїда та механізмом адаптації ваг оцінює стан каналу (сигнал, завади, втрати пакетів) і визначає доступний ліміт байтів для передачі.
2. **Стиснення даних (`HuffmanCodec.cs`)** — побітове стиснення кадрів алгоритмом Гаффмана зі спільним статичним словником сесії (заголовок 2 байти), що гарантує зменшення розміру навіть для коротких текстових повідомлень.
3. **Оптимізація черги (`FramePacker.cs`)** — відбір найважливіших кадрів у межах доступної ємності каналу за допомогою алгоритму динамічного програмування (задача про рюкзак 0/1) із подальшою бінарною серіалізацією.
4. **Криптографічний захист (`Security.cs`)** — шифрування та автентифікація за схемою *Encrypt-then-MAC* (`AES-256-CBC` + `HMAC-SHA256`), а також симуляція атаки модифікації байтів у каналі зв'язку.
5. **Прийом та відновлення (`Program.cs`)** — перевірка цілісності підпису HMAC, розшифрування, десеріалізація пакету, декомпресія Гаффмана та виведення підсумкових метрик ефективності.

## Встановлення та запуск

1. **Клонуйте репозиторій на локальний комп'ютер:**
   `git clone https://github.com/bartkivskyi-yurii/Secure-low-bandwidth-telemetry.git`

2. **Перейдіть у кореневу директорію проєкту** (де знаходиться файл `.csproj`):
   `cd Secure-low-bandwidth-telemetry`

3. **Відновіть залежності та згенеруйте файл конфігурації проєкту (`project.assets.json`):**
   `dotnet restore`
   *(Цей крок обов'язковий після першого клонування проєкту, щоб уникнути помилки `NETSDK1004`)*.

4. **Зберіть проєкт для перевірки відсутності помилок компіляції:**
   `dotnet build`

5. **Запустіть програму:**
   `dotnet run`

### Запуск через Visual Studio
1. Відкрийте файл рішення (`.sln`) або проєкту (`.csproj`) у Visual Studio.
2. У вікні **Solution Explorer** натисніть правою кнопкою миші на проєкт та оберіть **Restore NuGet Packages**.
3. Натисніть **F5** або кнопку **Start** для запуску.

## Структура проєкту

* `src/HuffmanCodec.cs` — Алгоритм Гаффмана (стиснення, декомпресія, коефіцієнт)
* `src/FramePacker.cs` — Модель кадру, рюкзак 0/1, серіалізація/десеріалізація
* `src/MlpLab.cs` — Нейронна мережа (MLP) для прогнозування пропускної здатності
* `src/Security.cs` — AES-256 + HMAC-SHA256 та імітація атаки
* `src/Program.cs` — Інтеграція конвеєра та виведення метрик
* `README.md` — Документація проєкту
